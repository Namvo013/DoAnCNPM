HƯỚNG DẪN KHỞI ĐỘNG WEB

1. CHUẨN BỊ SQL SERVER VÀ REDIS

- Đảm bảo SQL Server (instance SQLEXPRESS) đang chạy và database CNPM đã tồn tại.
- Backend đọc cấu hình kết nối trong backend-api\.env. Mặc định là SQL Server
  localhost\SQLEXPRESS, database CNPM, Windows Integrated Authentication.
- Đảm bảo Redis đang chạy theo REDIS_URL trong backend-api\.env (mặc định
  redis://localhost:6379/0). Có thể kiểm tra bằng lệnh:
  Test-NetConnection -ComputerName localhost -Port 6379
- Nếu SQL Server SQLEXPRESS đang dừng, mở PowerShell bằng quyền Administrator
  và chạy:
  Start-Service -Name 'MSSQL$SQLEXPRESS'

Không gửi file .env hoặc mật khẩu lên GitHub. Backend sẽ tự tạo các bảng cần
thiết trong database CNPM khi khởi động.

2. KHỞI ĐỘNG CÁC SERVICE (CHẾ ĐỘ MICROSERVICE)

Mở PowerShell tại thư mục dự án:
cd Nhom2ThuyetMinhDaNgonNgu

Chạy một lệnh:
powershell -ExecutionPolicy Bypass -File .\start-microservices.ps1

Script tự khởi động Auth, POI, Presence và Gateway, sau đó tạo token
nội bộ dùng chung. Chế độ này mở các cửa sổ PowerShell riêng cho từng service;
để các cửa sổ này mở trong lúc sử dụng. Khi các service đã khởi động, mở:
http://localhost:8000/login.html

Dừng từng service bằng Ctrl+C trong cửa sổ tương ứng. Không đóng cửa sổ Gateway
nếu vẫn muốn truy cập web. Nếu script báo thiếu .venv, xem mục 4 bên dưới.

3. KHỞI ĐỘNG ĐƠN GIẢN (BACKEND NGUYÊN KHỐI)

Nếu chỉ cần chạy ứng dụng trên một backend, mở PowerShell và chạy:
Set-Location 'C:\Users\User\OneDrive\Desktop\TMDNN\Nhom2ThuyetMinhDaNgonNgu\backend-api'
& .\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

Giữ cửa sổ PowerShell này mở. Không chạy chế độ này đồng thời với
start-microservices.ps1 vì cả hai đều sử dụng cổng 8000.

4. MỞ TRANG WEB

Trang quản trị:       http://localhost:8000/login.html
Trang khách:          http://localhost:8000/tourist-pwa/tour.html
Giao diện thử nghiệm: http://localhost:8000/experimental-tourist/
Tài liệu API:         http://localhost:8000/docs
Kiểm tra backend:     http://localhost:8000/api/health

Không cần tạo lại môi trường Python mỗi lần khởi động. Nếu thư mục
backend-api\.venv chưa tồn tại, tạo và cài đặt một lần:
Set-Location 'C:\Users\User\OneDrive\Desktop\TMDNN\Nhom2ThuyetMinhDaNgonNgu\backend-api'
py -3 -m venv .venv
& .\.venv\Scripts\python.exe -m pip install -e ".[dev]"

5. DÙNG GPS TRÊN ĐIỆN THOẠI (TÙY CHỌN)

GPS trên điện thoại cần trang web HTTPS. Sau khi backend đã chạy, mở một cửa sổ
PowerShell khác và chạy Cloudflare Tunnel:
& "C:\Program Files (x86)\cloudflared\cloudflared.exe" tunnel --url http://127.0.0.1:8000 --protocol http2 2>&1 | Select-String "trycloudflare"

Mở URL HTTPS trycloudflare.com được hiển thị, thêm /access-qr để hiện mã QR,
ví dụ:
https://ten-duong-dan.trycloudflare.com/access-qr

Giữ cửa sổ tunnel và các service/backend đang chạy. URL tunnel là công khai và
có thể thay đổi mỗi lần khởi động; chỉ dùng để thử nghiệm.
